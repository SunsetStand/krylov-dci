# Compressing the Q space by the SVD of H_PQ: what it gives and what it does not

Analysis of the proposal to return to the original effective-Hamiltonian/dCI
idea and handle the intractable Q space by taking an SVD of `H_PQ`, using its
right singular vectors to compress Q to at most the dimension of P, and then
building the effective Hamiltonian in that compressed space. Assessed against
Löwdin partitioning, against DMET's bath construction, against Li & Yang's dCI,
and against what this repository has already built and measured.

## Summary of the assessment

The idea is correct, and its central structural claim is exact rather than
approximate. It is also, in its literal form, **already implemented in this
repository and already measured**: it is the `m = 0` case of the existing
Krylov-dCI construction, which additionally preconditions it in a way that
strictly improves it. The measured `m = 0` to `m = 1` increment at the settings
tested is about `5e-8 Ha`, so at those settings the rank-`p` compression already
captures essentially the whole resolvent contribution.

What it does **not** do is fix accuracy, because it acts on the half of the
calculation that contributes exactly zero error. It fixes a scalability problem,
which is real and separate.

## The exact part, and it is the good news

Write the partitioned Hamiltonian with `|P| = p` and `|Q| = q`, `q >> p`:

```text
H_eff(E) = H_PP + H_PQ (E - H_QQ)^-1 H_QP
```

Take the SVD `H_PQ = U S W^dag` with `U` of shape `(p, r)`, `S` of shape
`(r, r)`, `W` of shape `(q, r)`.

**`r = rank(H_PQ) <= min(p, q) = p`, exactly.** The coupling operator therefore
maps P into an at most `p`-dimensional subspace of Q, namely `span(W)`, with no
approximation of any kind. Everything the P space can ever see of Q, through one
application of H, lives in `r <= p` directions.

This is a genuine structural fact and it is the correct analogue of the DMET bath
theorem: for a single determinant, the fragment-environment block of the
coefficient matrix has rank at most `n_frag`, so exactly `n_frag` bath orbitals
suffice. The rectangular shape is what does the work in both cases. The
intuition in the proposal is sound.

## Where the DMET analogy breaks, precisely

Substituting the SVD:

```text
H_eff(E) = H_PP + U S [ W^dag (E - H_QQ)^-1 W ] S U^dag
```

The bracket is `r x r`. The proposal, taken literally, replaces it by

```text
W^dag (E - H_QQ)^-1 W   ->   (E I_r - W^dag H_QQ W)^-1
```

**These are not equal.** The resolvent `(E - H_QQ)^-1` does not preserve
`span(W)`: `H_QQ` rotates vectors out of it, so inverting the projection is not
the projection of the inverse. Compressing Q to `span(W)` and only then building
the effective Hamiltonian is therefore an approximation, not an identity.

In DMET the corresponding step *is* exact, and the reason is worth being explicit
about. There the Schmidt decomposition is of the **state**, and the
fragment-plus-bath space contains that state exactly, so nothing is lost. Here
the rank-`p` structure is a property of the **operator** `H_PQ`, and the dynamics
inside Q, carried by `H_QQ`, then leaks out of `span(W)`. The analogy holds for
the coupling and fails for the Q-space dynamics. That difference is exactly the
gap between an exact embedding and a good first approximation.

## The systematic repair is standard, and cheap

The exact object is the `r x r` matrix-valued resolvent
`G(E) = W^dag (E - H_QQ)^-1 W`. Its exact representation is a **matrix continued
fraction**, generated by block Lanczos on `H_QQ` with starting block `W`:

```text
K_m = span{ W, H_QQ W, H_QQ^2 W, ..., H_QQ^m W }     dim <= (m+1) r
```

The Galerkin approximation to `G(E)` in `K_m` reproduces the moments
`<W| H_QQ^k |W>` exactly for `k <= 2m+1`. So:

- `m = 0` is the proposal as stated: dimension `r <= p`, exact through moments 0
  and 1;
- each further order costs `r` more basis vectors and `r` more `H_QQ`
  applications, and is systematically convergent.

**No off-diagonal element of `H_QQ` is ever needed, and `H_QQ` is never stored.**
The construction needs only the action `v -> H_QQ v`, which is an ordinary
sigma-vector operation that PySCF's direct CI provides and that this
repository's backend already implements. That answers the motivating concern
directly: the `q x q` problem is not merely mitigated, it is removed.

## This is what the repository already built

`dm_svd_dci/_legacy_krylov_propagator.py`:

- `build_krylov_basis_mgs` computes `B0 = MGS(A_q * H_QP)` where
  `A_q = 1/(E0 - diag H_QQ)`. Note `span(MGS(H_QP)) = span(W)`, the same space
  the SVD right singular vectors give, obtained by orthogonalization instead of
  by SVD. So **`m = 0` is the proposal**, with one addition: the diagonal
  resolvent weighting.
- That weighting is not cosmetic. `A_q` is the zeroth-order approximation to the
  true resolvent action, so `span(A_q * H_QP)` is a better `r`-dimensional
  approximation to the space the exact resolvent wants than `span(H_QP)` is. It
  is a strict improvement on the literal proposal at identical cost.
- `propagate_krylov_mgs` is the block-Lanczos extension to `m >= 1`.

Measured, N2 CAS(10,10)/cc-pVDZ through the legacy pipeline, on 2026-09-17:

| `svd_eps` | `|Q|` | `E(m=1) - E(m=0)` |
|---|---|---|
| 1e-2 | 17 | `~1e-14 Ha` |
| 3e-3 | 232 | `-4.9e-08 Ha` |

So going from the rank-`r` compression to one further Lanczos order changed the
energy by about `5e-8 Ha`. **At these settings the `m = 0` compression already
captures essentially the entire resolvent contribution**, which is direct
numerical support for the proposal.

One caveat, stated rather than smoothed: those `|Q|` values are 17 and 232 in the
**Schmidt product basis**, not the astronomically large determinant Q space the
proposal is aimed at. Continued-fraction convergence is governed by the spectral
spread of `H_QQ` relative to the distance from `E` to the spectrum of `H_QQ`. A
determinant Q space has a far wider spectrum, so `m = 0` will not automatically
be as good there. It has to be measured.

## The bottleneck it solves, and the one it does not

| Cost | Without compression | With rank-`r` compression |
|---|---|---|
| Storing `H_QQ` | `O(q^2)` — impossible | never formed |
| `H_QQ` applications | — | `(m+1) r` sigma-vectors |
| Storing the Q-space basis | — | **`O(q r)`** |

The compression converts `q^2` into `q r`, which is the difference between
impossible and possible. It does not remove the linear dependence on `q`: every
column of `W` is a full Q-space vector. At `q ~ 1e9` and `r ~ 1e3` that is `1e12`
doubles.

**This is exactly the bottleneck this project already measured.** Peak memory on
N2 is a constant `4.2 x M x D`, where `M` is the determinant-space dimension,
while the `q x q` Hamiltonian is `0.1` to `2.3 percent` of peak; and the
Six-Week report independently identifies `H^emb` construction as 87 to 93 percent
of wall time, dominated by the `H_AB` sigma-vector projection at `O(D^2 M)`.
Going further than `O(q r)` requires one of:

1. **screening or sparsity in Q** — which is precisely what Li & Yang's dCI does;
2. **never materializing the Q vectors**, processing them in batches, trading
   memory for time, which is what `streaming_ops.py` was written for;
3. **restricting Q to a selected subspace**, which reintroduces selection and
   with it the CIPSI/HCI family.

## Relation to Li & Yang's dCI

`docs/theory/formalisms.md` records their method as *cluster-based recursive
screening with an incremental Schur complement resolvent*. The Schur complement
**is** `H_PP + H_PQ (E - H_QQ)^-1 H_QP`, so both approaches target the same
object. They differ only in how they avoid touching all of Q:

- **Li & Yang**: never build a Q basis at all; build the resolvent incrementally
  over a recursively screened cluster hierarchy.
- **This proposal**: build an explicit, minimal, `rank(H_PQ)`-dimensional Q basis
  from the coupling itself.

These are complementary rather than competing, and the distinction is the
positioning `formalisms.md` already states: same goal, different mathematical
foundation. A route that reaches the same Schur complement through an exact
rank bound on the coupling, refined by a convergent block-Lanczos hierarchy, is
a legitimate and clearly-stated alternative foundation.

**Novelty caution.** Block and band Lanczos for matrix-valued Green's functions,
seeded by the coupling block, is long established in nuclear physics and
solid-state spectral theory, and the Gate A review already concluded that the
effective-Hamiltonian half of this project is classical wave-operator theory.
This proposal sits squarely in that half. It should be treated as a sound and
well-founded engineering route, not as a novelty claim, until the Lanczos
continued-fraction literature has been checked specifically.

## The decisive objection: it optimizes the half whose error is already zero

The error budget on the current path was measured and separates exactly:

```text
E_downfolded - E_embedded  =  0.0000 mH     in every cell of the H2O scan
E_embedded   - E_reference =  all of it
```

The Q-space treatment, in the current architecture, contributes **no error at
all**. At convergence the downfolding reproduces the exact diagonalization of
`H_emb`. All of the remaining error, `9.47 mH` at `eps = 3e-3` on N2, is
truncation of the **model space P**.

A rebuild around the SVD of `H_PQ` would therefore improve cost and reach, not
accuracy. It is the right move if the goal is CAS(14,10) and beyond. It is not
the move if the goal is chemical accuracy at the sizes already reachable.

## What the record says about the accuracy target

Chemical accuracy has already been reached on N2 by this project, and the
configuration matters:

| Job | Space | `eps` | `D` | grid ceiling | Error | Downfolding |
|---|---|---|---|---|---|---|
| 15371, gs | CAS(10,10) | 1e-3 | 4,668 | 184,756 | `+0.144 mH` | per-state Löwdin `m=1` |
| 15372, sa 5 states | CAS(10,10) | 1e-3 | 15,198 | 184,756 | all within `±1 mH` | per-state Löwdin `m=1` |
| Gate C, sa 4 states | CAS(10e,9o) | 3e-3 | 2,517 | 43,186 | `9.47 mH` | shared residual-dressed Omega |

Three differences separate the `±1 mH` row from the `9.47 mH` row: the
threshold and hence `D`; the active space; and, most importantly, **per-state
Löwdin centering versus a single shared wave operator**.

This repository's own record states the mechanism:
"the earlier 'excited states degrade with `m`' was an artifact of shared Krylov
bases", and "the Krylov basis MUST be centered at the target state's energy".
Hypothesis H7, shared versus per-state Omega, was tested only on H2O and returned
`INDISTINGUISHABLE` — on the system with the least discriminating power, whose
blocks are too small to express the effect.

**There is a structural connection to the proposal here, and it is the most
useful thing in this analysis.** The compression `span(W)` from the bare SVD of
`H_PQ` is energy-independent, so it is naturally *shared* across states. Adding
the diagonal resolvent preconditioning `A_q = 1/(E_k - diag H_QQ)` makes it
naturally *per-state*, because `E_k` differs per state. The choice of whether to
precondition is therefore the same choice as shared versus per-state
downfolding, and the record says that choice is what decided chemical accuracy
for the excited states.

## Recommendation

1. **Before any rebuild, run H7 properly on N2 at `eps = 1e-3`**: per-state
   Omega against shared Omega, four states, corrected active space. The record
   predicts this is worth roughly an order of magnitude on the excited states,
   and it is the cheapest experiment with the largest expected effect. If it
   reproduces the `±1 mH` row, the accuracy question is answered and no reset is
   needed.
2. **Separate the states.** The weighted error hides a strongly uneven
   distribution: at `eps = 1e-2` the weighted error is `18.20 mH` while the worst
   single state is `38.59 mH`. Measure the ground state alone at the same
   thresholds. If the ground state is already near chemical accuracy, the problem
   is the cost of a shared four-state basis, not the method, and the fix is
   per-state treatment rather than a new Q-space scheme.
3. **Then, and separately, adopt the rank-`r` compression as the scalability
   route**, because it is correct, already implemented at `m = 0`, measured to be
   nearly exact at `m = 0` at the settings tested, and needs only sigma-vector
   products. Pair it with batching over Q, since `O(q r)` storage is the
   remaining wall.
4. **Do not frame it as novel** without checking the block-Lanczos
   continued-fraction literature.
